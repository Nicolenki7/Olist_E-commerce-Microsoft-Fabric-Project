Cómo se calcula

Agregado mensual calculado una vez desde el dataset público y versionado.

  1. Fuente: dataset público de Olist (olist_order_items_dataset y olist_orders_dataset), agregado una vez y versionado.
  2. Solo se cuentan pedidos con estado pagado, aprobado, facturado, enviado o entregado; cancelados quedan fuera del GTV.
  3. GTV = suma de price de los ítems; el flete se informa aparte, no se suma a la facturación.
  4. El ticket medio es GTV / pedidos distintos, no el ticket de una línea.

Qué no dice este informe

Lo que este recorte no permite afirmar.

  • 2016 y 2018 están incompletos: el dataset corta a principios de septiembre de 2018.
  • No hay coste del producto, así que no se puede calcular margen, solo ingreso bruto.
  • Los precios están en reales de 2016-2018, sin ajuste por inflación.
  • No se versionan los CSV originales (32 MB); el resumen es lo que queda auditable en el repo.
